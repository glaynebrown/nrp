# NRP

Study app built from Bella's NRP notes (9th edition). Algorithm cards (Reference / Study / Run it),
med math (1:10,000 explained, calculator, practice), PEEP/PIP + compression rhythm visuals, Pencil notes.

- Content to edit: `content.js`
- Firebase project: `nrp-study-jjoqh` (Firestore rules in `firestore.rules`, deployed with the Firebase CLI)
- Site files for GitHub Pages: index.html, styles.css, app.js, content.js, store.js, ink.js,
  firebase-config.js, sw.js, manifest.json, icon-192.png, icon-512.png, apple-touch-icon.png
